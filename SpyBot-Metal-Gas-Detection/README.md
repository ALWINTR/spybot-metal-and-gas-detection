\# 🤖 SpyBot with Metal and Gas Detection



\## 📌 Overview

SpyBot is a long-range surveillance robot designed for monitoring hazardous and restricted environments.  

It provides wireless control, live sensor feedback, and modular expansion capability.



\## 🚀 Features

\- Bluetooth-based remote control

\- Gas detection (Smoke / LPG)

\- Metal detection

\- Flame detection

\- Temperature monitoring

\- Servo-based camera or gripper control



\## 🧠 Technologies Used

\- Arduino (UNO / Nano)

\- Embedded C/C++

\- Bluetooth Module (HC-05 / HC-06)

\- Gas Sensor (MQ series)

\- Metal Detector Module

\- Servo Motor

\- Motor Driver (L298N / L293D)



\## 📂 Code Structure



\### 1️⃣ Main Control \& Sensors

Path:

arduino/spybots\_main\_control/



Handles robot movement and environmental sensing.



\### 2️⃣ Servo / Camera Control

Path:

arduino/servo\_camera\_control/



Controls servo motor and alternate robot movement.
